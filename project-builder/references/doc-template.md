## 主要功能

列出核心功能点，使用无序列表，每个功能点一句话描述清楚。

示例写法：
- 支持批量压缩指定目录下的 PNG 和 JPG 图片
- 可自定义目标文件大小（默认 200KB）
- 压缩后保持原始目录结构，不覆盖原图
- 支持递归处理子目录
- 显示压缩进度和每张图的压缩率

## 使用方法

说明基本运行 / 调用方式，包含：
1. 基本命令或调用方式
2. 参数说明（如有）
3. 常见用法示例

示例写法：
### 基本用法
```bash
python compress_images.py <图片目录>
```

### 参数说明
| 参数 | 说明 | 默认值 |
|------|------|--------|
| `<图片目录>` | 要压缩的图片所在目录 | 必填 |
| `--size` | 目标文件大小（KB） | 200 |
| `--recursive` | 递归处理子目录 | 关闭 |
| `--output` | 输出目录 | 原目录下新建 `compressed/` |

### 示例
```bash
# 压缩当前目录下的图片，目标大小 100KB
python compress_images.py ./photos --size 100

# 递归处理所有子目录
python compress_images.py ./photos --recursive
```

## 输入输出示例

至少提供一个**可运行的完整示例**，包含输入和预期输出。

示例写法：
### 示例：压缩单张图片

**输入：**
```bash
python compress_images.py ./test_images --size 50
```

目录 `./test_images` 内容：
```
test_images/
├── photo1.jpg  (2.3 MB)
└── photo2.png  (1.8 MB)
```

**预期输出：**
```
[1/2] 压缩 photo1.jpg: 2.3MB -> 48KB (压缩率 97.9%)
[2/2] 压缩 photo2.png: 1.8MB -> 45KB (压缩率 97.5%)

完成！共压缩 2 张图片，输出目录: ./test_images/compressed/
```

输出目录内容：
```
test_images/
├── photo1.jpg
├── photo2.png
└── compressed/
    ├── photo1.jpg  (48 KB)
    └── photo2.png  (45 KB)
```
